# Planning guide V3

Adapted directly from https://github.com/tmd2-lang/lady-victoria-investment-guide.
Original React components, Tailwind theme, and GSAP animations are the foundation.
Planning package data is a snapshot of src/data/packages.ts in the main website.
À la carte services retain Tanah’s supplied draft menu.

Build with `npm run build`; output goes to ../v3.
Preview at http://127.0.0.1:4387/v3/ using the existing static server.
V1 and V2 are separate and unchanged. Inquiry preparation stays local;
continuing to the live website is an explicit user action.

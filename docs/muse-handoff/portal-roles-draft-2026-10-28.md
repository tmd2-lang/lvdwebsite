# Portal roles: draft for Irene to approve (Oct 28, 2026)

Irene asked us to define what each portal role can see and do. This is a draft. Nothing changes in the portal until Irene approves it.

## How it works today

Everyone the studio invites to a couple's portal sees every page. Only two actions are limited:

- Editing the guest list: Client and Partner only.
- Approving a moodboard: Client and Partner only.

So right now Family and Guest can see the budget, the invoices and the documents.

## Proposed

| Page | Client | Partner | Family | Guest |
|---|---|---|---|---|
| Overview | See | See | See | See |
| Checklist | See + tick off | See + tick off | See | — |
| Budget & payments | See | See | — | — |
| Moodboard | See + approve | See + approve | See | — |
| Documents | See | See | See | — |
| Images | See | See | See | See |
| Guests | See + edit | See + edit | See | — |
| Timeline | See | See | See | See |

The Studio-only documents stay hidden from all four roles, the same as now.

## Questions for Irene

1. Should Family see the budget? Some parents are paying, so they may need to. If so, we can add a "Family (paying)" role.
2. Should Guest exist at all, or is it really for the wedding party (a planner or day-of helper)?
3. Should Family be able to tick off checklist items?

Once she answers, we'll build it and show each role's access on the invite screen.
